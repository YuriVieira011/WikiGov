# 🏛️ Wiki.gov

Plataforma leve de artigos e serviços governamentais públicos, com o objetivo de organizar informações e páginas do próprio Gov.br de forma simples e direta para uso cotidiano.

## 🚀 Status do Projeto
Em desenvolvimento 🚧

## ✨ Funcionalidades
- Sistema de filtros
- Modo Escuro, Claro e de Alto Contraste
- Sistema de busca
- Cards para filtragem de serviços

## 🛠️ Tecnologias Utilizadas
- HTML / CSS / JavaScript
- Bootstrap
- Node.js
- EJS

## 📥 Como Instalar e Executar

Certifique-se de ter o [Node.js](https://nodejs.org/) instalado na sua máquina. Siga os passos abaixo:

```bash
# Clone o repositório
git clone https://github.com/YuriVieira011/WikiGov/

# Entre na pasta do projeto
cd WikiGov

# Instale as dependências
npm install

# Inicie o servidor
npm start
